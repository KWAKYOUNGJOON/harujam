# 하루잠 (Harujam) v0.1

의사 처방이나 회원가입 없이 무료로 사용할 수 있는 **한국어 CBT-I 교육용 PWA 프로토타입**입니다.

- 6주 학습과정 및 이해도 퀴즈 (학습 순서는 자유)
- 수면일지 작성/수정/삭제
- 추정 수면시간 및 추정 수면효율 자동 계산, 최근 7개 기록 그래프
- 잠에 대한 생각 다시 보기, 1분 호흡 연습
- 기기 로컬 데이터 저장, JSON 백업/복원 및 CSV 내보내기
- 외부 라이브러리 / 광고 / 유료 결제 / 계정 / 서버 API 없음
- HTTPS에서 홈 화면에 설치, 설치 후 오프라인 사용 가능

## 바로 사용해 보기

`index.html`을 브라우저로 열면 대부분의 기능이 실행됩니다. 단, 브라우저 보안 정책상 로컬 파일로 연 경우 PWA 설치 및 오프라인 서비스 워커는 활성화되지 않습니다. 브라우저의 파일 접근 방식에 따라 로컬 저장이 제한될 수 있습니다.

## 갤럭시에서 앱처럼 설치하기 (무료)

1. GitHub에서 새 **Public** 저장소를 만듭니다. 예: `harujam`.
2. 이 폴더 안의 파일 전체를 저장소 최상위 경로에 업로드합니다. **실제 건강 기록 JSON/CSV는 업로드하지 마세요.**
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**, `main` / `/(root)`를 선택해 저장합니다.
4. 배포 주소 `https://사용자명.github.io/harujam/`을 갤럭시 **Chrome**에서 엽니다.
5. Chrome의 `⋮` 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다 (브라우저/기종에 따라 표기가 다름).
6. 첫 접속 뒤부터는 오프라인 이용도 가능합니다. 브라우저 및 OS 정책에 따라 저장 공간 정리 시 데이터가 사라질 수 있으므로 JSON 백업을 권장합니다.

GitHub Pages 사용 정책 및 배포 제한에 따라 공개 저장소 무료 호스팅을 사용할 수 있습니다. 앱 자체의 모든 기능은 무료입니다.

## 구조

- `index.html`: 화면 구성
- `style.css`: 모바일/데스크톱 반응형 스타일
- `app.js`: 6주 학습, 수면일지, 계산, 내보내기/복원, 퀴즈, 호흡 기능
- `manifest.webmanifest`: 홈 화면 설치 정보
- `sw.js`: 정적 자원 오프라인 캐싱
- `icon-192.png`, `icon-512.png`: 아이콘

## 수면일지 계산

- 침대에 있던 시간 = 침대에서 나온 시각 − 침대에 들어간 시각 (자정 경과 자동 처리, 24시간 이내)
- 추정 수면시간 = 침대에 있던 시간 − (입면 소요 + 밤중 각성 + 최종 각성 이후 침대에 있던 시간)
- 수면효율 = 추정 수면시간 / 침대에 있던 시간 × 100
- 현재 UI는 침대에 있던 시간이 2~16시간인 기록만 허용합니다. 교대근무/여러 수면 구간에는 적합하지 않을 수 있습니다.

계산 결과는 자가 보고된 기록에 기반한 추정치이며 의료적 진단에 사용해서는 안 됩니다.

## 개인정보

기록은 브라우저의 `localStorage`에 저장되며 앱 코드가 서버로 기록을 전송하지 않습니다. 다만 GitHub Pages 등 호스팅 사업자는 사이트 요청 시 통상적 접속 로그를 수집할 수 있습니다. JSON/CSV 파일을 사용자가 내보내거나 공유하면 그 파일에 건강 관련 개인 기록이 포함됩니다.

## 안전과 이용 범위

이 코드는 교육용 **프로토타입**입니다. 의료기기로 허가·임상 검증을 받은 소프트웨어가 아니며, 불면증의 진단이나 전문 치료를 대체하지 않습니다. 특히 개인별 수면시간 제한이나 취침 시각 자동 처방 기능은 의도적으로 제외했습니다.

심한 주간 졸림, 수면무호흡 의심, 양극성장애, 발작 질환, 수면 중 이상행동 또는 졸음운전 위험이 있다면 수면시간 제한을 스스로 시작하지 말고 의료 전문가에게 상담하세요. 수면제 복용량을 앱에 따라 변경해서는 안 됩니다.
